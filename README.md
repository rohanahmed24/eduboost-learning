# Eduboost

A responsive online-learning frontend concept with reusable content layouts and motion.

[Live demo](https://eduboost-web.vercel.app)

## Implemented scope

- Course catalogue and detail layouts
- Teacher profile pages
- Pricing, testimonials, FAQ, and marketing sections
- Responsive components and scroll-based motion
- Reduced-motion support in animated UI

## Stack

Next.js · React · TypeScript · Tailwind CSS · Framer Motion

## Run locally

```bash
npm install
npm run dev
```

The application lives in the `web` workspace. Open [http://localhost:3000](http://localhost:3000).

## Project status

Frontend portfolio concept. Course, teacher, and pricing content is demonstrative; this README does not claim a production learning backend.
